# Site Images

General website imagery — hero backgrounds, lifestyle photos, section visuals.

## In use
- `og-image.jpg` — the site's default link preview image (2400×1260 JPEG). Generated by
  `designs/thryve-growth-co/og-image/build_og.mjs` (outside this repo). Do not hand edit
  or re-crop it: `src/lib/seo/og.ts` carries a `?v=` cache token taken from the file's
  sha256, and `scripts/check-og-image.mjs` fails the build if the two ever disagree. If
  the picture is regenerated, paste the new token the build script prints.

## Suggested Images
- `hero-bg.jpg` — Optional hero background texture or abstract (if not using Rachel's photo)
- `coaching-session.jpg` — Coaching/meeting lifestyle image (for services pages)
